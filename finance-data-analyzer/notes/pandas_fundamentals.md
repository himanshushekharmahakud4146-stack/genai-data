## 📚 Concepts Learned

### 1. What is Pandas?

Pandas is a Python library used for working with structured and
tabular data.

It provides two important data structures:

- `Series` → One-dimensional data
- `DataFrame` → Two-dimensional tabular data

A DataFrame can be thought of as a table containing rows and columns.
